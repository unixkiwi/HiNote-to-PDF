# HiNote-to-PDF

HiNote-to-PDF is a tool to convert `.hinote` files from the Huawei Notes app into PDF files.

## References

This project is inspired by and based on the work of [Hu Wangpeng](https://github.com/huwangpeng) and his
project [HiNoter](https://github.com/huwangpeng/Hinoter), which is also designed to convert `.hinote` files into
PDFs.hino
